# test-todo-app-pj-army

A small todo app used as a playground for [pj-army](https://github.com/pieterjandebruyne/pj-army).

## What this is

This repository intentionally starts almost empty — it's a sandbox where new ideas and small projects get tested before being moved to their proper home. The todo app code will live here once scaffolding is added.

## Running the app

Once the project is scaffolded, you'll be able to run it with:

```bash
npm install
npm start
```

(Exact commands will be updated when the code arrives.)

## Code location

The source code will live at the repository root once added. The `.pj-army/` directory is managed by pj-army and should not be edited manually.
